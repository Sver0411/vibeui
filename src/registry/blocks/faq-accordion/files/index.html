常见问题

你可能想先知道

可以免费试用吗？

可以。所有付费方案都带 14 天完整功能试用，不需要绑定信用卡。试用期结束后如果不主动升级，账号会自动回落到免费版，已有数据不会被删除。

中途升级或降级，费用怎么算？

升级立即生效，系统按剩余天数折算差价；降级会在当前计费周期结束时生效，已支付的费用不会浪费。

支持哪些付款方式？

支持微信支付、支付宝，以及 Visa / Mastercard 等主流信用卡。团队版年付还可以走对公转账并开具增值税专用发票。

数据可以导出吗？

随时可以导出。项目内容支持 Markdown 与 JSON 两种格式，附件与图片按原文件打包下载，不做任何格式锁定。
