Scroll this box. The bar at the top fills according to how far through the content you are — exactly how reading-progress indicators work on blogs and documentation sites.

The component listens to scroll events on the scroll container, computes scrollTop / (scrollHeight - clientHeight) and updates a CSS width. Passive listeners and requestAnimationFrame throttling keep it at 60fps.

Progress indicators like this one give users a sense of place and remaining effort, which measurably improves completion rates on long-form content.

Because the bar is driven by scroll position rather than a timer, it is fully deterministic: scroll back up and the bar empties again.

Styling is one div with a gradient or solid fill. The rounded ends and subtle shadow keep it visible without shouting.

Accessibility note: mark it aria-hidden — it is purely decorative, since the scroll position itself is already exposed to assistive technology.
