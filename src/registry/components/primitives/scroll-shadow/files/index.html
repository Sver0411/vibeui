下拉菜单、抽屉、评论区、通知面板——凡是内容可能超出固定高度的容器，都需要一个「下面还有」的视觉暗示，否则用户根本不知道该滚。

最轻量的暗示就是边缘渐隐阴影：内容贴着边被裁切的地方，叠一层从容器背景色渐变到透明的遮罩。

判定条件只有两个：scrollTop 大于 0 说明上方被裁切；scrollTop 小于 scrollHeight 减去 clientHeight 说明下方被裁切。

两个条件互相独立，所以上下遮罩要分开控制，可能出现「只有顶部有阴影」的中间态。

性能上必须 rAF 节流：滚动事件每秒触发几十次，但一帧只需要写一次 opacity。

深色主题下遮罩渐变要用容器的实际背景色，写死白色会在暗色界面留下一块亮斑。

继续往下滚，观察底部阴影在触底时的淡出——这就是完整的效果闭环。

最后一行：滚到这里，上下阴影应该全部消失。
