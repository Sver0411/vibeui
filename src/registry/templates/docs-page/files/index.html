介绍

这是一套文档站布局模板：左侧固定导航、中间正文、右侧页内目录。滚动时右侧目录自动高亮当前章节。

💡 所有区块间距与字体收敛在 CSS 变量里，改一处即可整体换风格。

安装

使用你熟悉的包管理器安装依赖：

npm install
npm run dev

资源注册

每个资源是一个目录，包含元数据与源码文件；注册中心按约定自动加载，无需手动登记代码文件。

主题变量

颜色、圆角、密度全部走 CSS 变量，深浅主题通过根节点 data 属性切换。

命令行

构建命令会同时完成类型检查与静态生成，产物可直接部署到任意静态托管。
